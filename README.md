## The entry

> I put focus time on my calendar, so my coworkers booked a meeting to discuss why I'm never free.

96 characters, one line, written from scratch for this bounty.

## Strategy (why this line)

The judge weighs, in order: on-subject joke, funny, one line, fresh, clear
on first read.

- **On-subject joke:** the whole line is the joke — a setup and a punchline
  about working in an office, not a caption or stray observation.
- **Funny:** the punchline pays off with irony anyone in an office
  recognises — the tool meant to protect your time (focus time) creates the
  very thing that eats it: a meeting about why you have no time.
- **One line:** a single sentence, setup and punchline on the same line, no
  rambling around it.
- **Fresh:** a specific detail (calendar "focus time") instead of a generic
  complaint, and a new angle — focus time backfiring — rather than the
  reply-all / printer / "per my last email" jokes the field is full of.
- **Clear on first read:** plain words, no reference the reader cannot
  follow, tight wording (96 of 200 characters).

## How to run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and self-validates it against the
gate: exactly one line, 1–200 characters, not only whitespace.
Deterministic — the line is a constant; no input, no network, no
randomness. Python 3 standard library only.
